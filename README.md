# WeWater website (Astro rebuild)

Static rebuild of [wewater.org](https://www.wewater.org) with Astro. No CMS: every page, project and blog post lives in this repo and is edited in code.

- Plan and status of the rebuild: [PLAN.md](PLAN.md)
- How the site is organised and how to edit it: [CLAUDE.md](CLAUDE.md)

```bash
nvm use
npm install
npm run dev
```
